Application Android de **La Khôllation**.

**Installer :** sur le téléphone Android, télécharge `khollation.apk` ci-dessous, ouvre-le, puis autorise l'installation si Android le demande (« Autoriser cette source »).

L'application affiche le site en ligne : les produits, les prix et les nouveautés sont toujours à jour, sans réinstaller l'application.

Sur iPhone, pas de fichier à télécharger : ouvre https://khollation.github.io/commande/ dans Safari, touche « Partager » puis « Sur l'écran d'accueil ».
